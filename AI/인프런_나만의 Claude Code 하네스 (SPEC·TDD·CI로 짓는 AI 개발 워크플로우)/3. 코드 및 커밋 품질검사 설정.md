# 3. 코드 및 커밋 품질검사 설정

## 3.1 이론-품질관리설정(린팅과 커밋검사)
- Git Hook: 커밋에 끼어드는 스크립트
```shell
git commit

.git/hooks/pre-commit 실행

exit 0 - 커밋 진행
exit 1 - 커밋 차단
```
- pre-commit: 커밋 객체 생성 전. 코드 품질 검사
- commit-msg: 메시지 기록전. 형식 검사

- Husky
  * Hook을 팀이 공유하는 방법
  * `.git/hooks/pre-commit`는 git 추적 안됨
  * `.husky/pre-commit` git 추적됨
  * Husky가 Git에게 Hook폴더를 `.git/hooks/` 대신 `.husky`에서 찾아라
