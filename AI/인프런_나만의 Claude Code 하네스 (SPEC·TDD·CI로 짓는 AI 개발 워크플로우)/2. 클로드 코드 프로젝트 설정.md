# 2. 클로드 코드 프로젝트 설정

## 2.1 이론-클로드코드 개발 환경 설정

### Claude는 세션간 기억이 없다
- LLM은 대화를 저장하지 않는다. 이것은 버그가 아니라 설계다.

### CLAUDE.md = AI 온보딩 문서
- 프로젝트 개요, 파일구조, 코딩컨벤션, 빌드 & 테스트 명령어 - 200줄 이하 유지

### `/init`- CLAUDE.md 자동 생성
- 핵심파일 스캔
- 구조 패턴 파악
- CLAUDE.md 초안 생성
  * 자동 생성된 규칙집 - 출발점이지 완성품이 아니다
- `/init`을 그대로 쓰는 것은 바이브코딩과 같은 실수다. **사람이 검토하고 보강해야 한다.**

### Mermaid - 다이어그램도 코드처럼
- 코드는 바뀐다. 한달 뒤 다이어그램은 구식이 된다. **틀린문서는 없는 것보다 나쁘다.**
- 텍스트로 정의: 마크다운처럼 쓰면 다이어그램으로 렌더링
- Git으로 관리: diff로 변경 추적, 코드와 함께 버전 관리
- AI가 자동 생성: Claude가 코드 분석 -> 다이어그램 즉시 생성
- `/mermaid-diagram` 스킬 하나로 현재 아키텍처를 브라우저에서 확인한다.
